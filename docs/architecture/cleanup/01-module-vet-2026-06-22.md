## user-management  `typescript`

**Health:** vet `yellow` → adversary-adjusted **`yellow`** (verdict accuracy: *accurate*)

**Summary:** user-management is a genuinely well-architected, mature TS module: clean ports/use-cases(functions)/adapters(classes) layering, no cross-module imports, tenant_id (iq_tenant_id) as composite PK and in every tenant-scoped query, proper Cerbos PEP gating on mutations, publish-after-commit rich events, and cross-module reads done correctly via HTTP adapters behind ports with retry/timeout/cache.
